¿Qué librería utilicé?

Chart.js es una librería de JavaScript para crear gráficos interactivos en páginas web. La incorporé desde su CDN y la usé para mostrar la cantidad de libros leídos de enero a junio.

Los botones cambian el gráfico entre barras y línea. Me resultó interesante que Chart.js genera el gráfico, las etiquetas y la interacción a partir de los datos y una configuración, en lugar de tener que dibujar cada elemento manualmente con JavaScript y HTML.
